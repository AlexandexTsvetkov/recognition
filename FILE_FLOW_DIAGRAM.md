# Диаграмма потока файла

## Текущая реализация (проблемная)

```
┌─────────────┐
│   Клиент    │
│  (мобилка)  │
└──────┬──────┘
       │ HTTP POST (multipart/form-data)
       │ Файл: 10MB
       ▼
┌─────────────────────┐
│   API Gateway       │
│   (порт 8080)       │
│                     │
│ 1. Получает файл    │
│ 2. Конвертирует     │
│    FilePart → byte[]│
│ 3. Валидирует       │
└──────┬──────────────┘
       │ HTTP POST (JSON)
       │ RecognitionTaskRequest
       │ { audioData: byte[10MB] }
       │ Размер: ~13MB (base64)
       ▼
┌─────────────────────┐
│  Request Service    │
│  (порт 8082)        │
│                     │
│ 1. Создает задачу   │
│ 2. Сохраняет в БД   │
│ 3. Сериализует      │
│    byte[] → JSON    │
└──────┬──────────────┘
       │ Kafka Producer
       │ Topic: recognition-tasks
       │ Message: { audioData: byte[10MB] }
       │ Размер: ~13MB
       ▼
┌─────────────────────┐
│   Kafka Broker      │
│                     │
│ Хранит сообщение    │
│ Размер: ~13MB       │
│ ⚠️ Проблема!        │
└──────┬──────────────┘
       │ Kafka Consumer
       │ Десериализует JSON → byte[]
       ▼
┌─────────────────────┐
│ Processing Service  │
│ (порт 8083)         │
│                     │
│ 1. Получает byte[]  │
│ 2. Отправляет в     │
│    SpeechKit (gRPC) │
│ 3. Обрабатывает     │
└─────────────────────┘
```

### Проблемы:
- ❌ Файл передается через Kafka (неэффективно)
- ❌ Множественная сериализация/десериализация
- ❌ Дублирование в памяти (4 копии файла)
- ❌ Ограничение размера сообщений Kafka

---

## Рекомендуемое решение (с S3/MinIO)

```
┌─────────────┐
│   Клиент    │
│  (мобилка)  │
└──────┬──────┘
       │ HTTP POST (multipart/form-data)
       │ Файл: 10MB
       ▼
┌─────────────────────┐
│   API Gateway       │
│   (порт 8080)       │
│                     │
│ 1. Получает файл    │
│ 2. Загружает в S3   │
│    ────────────────│
│    PUT /audio/{id}  │
│    ────────────────│
│ 3. Получает URL     │
│    s3://bucket/123  │
└──────┬──────────────┘
       │ HTTP POST (JSON)
       │ RecognitionTaskRequest
       │ { audioFileUrl: "s3://..." }
       │ Размер: ~200 байт
       ▼
┌─────────────────────┐
│  Request Service    │
│  (порт 8082)        │
│                     │
│ 1. Создает задачу   │
│ 2. Сохраняет в БД   │
│ 3. Отправляет URL   │
│    в Kafka          │
└──────┬──────────────┘
       │ Kafka Producer
       │ Topic: recognition-tasks
       │ Message: { audioFileUrl: "s3://..." }
       │ Размер: ~200 байт ✅
       ▼
┌─────────────────────┐
│   Kafka Broker      │
│                     │
│ Хранит только URL   │
│ Размер: ~200 байт   │
│ ✅ Эффективно!       │
└──────┬──────────────┘
       │ Kafka Consumer
       │ Получает URL
       ▼
┌─────────────────────┐
│ Processing Service  │
│ (порт 8083)         │
│                     │
│ 1. Получает URL     │
│ 2. Скачивает из S3  │
│    ────────────────│
│    GET /audio/{id}  │
│    ────────────────│
│ 3. Обрабатывает     │
│ 4. Удаляет из S3    │
└──────┬──────────────┘
       │
       ▼
┌─────────────────────┐
│   S3/MinIO          │
│                     │
│ Хранит файлы         │
│ Временное хранилище  │
│ Автоудаление через   │
│ TTL (24 часа)        │
└─────────────────────┘
```

### Преимущества:
- ✅ Kafka работает с маленькими сообщениями
- ✅ Файл хранится только в S3 (1 копия)
- ✅ Меньше сериализации
- ✅ Нет ограничений размера
- ✅ Масштабируемость

## Сравнение использования памяти

### Текущий подход (10MB файл):
```
API Gateway:     10MB (byte[])
Request Service: 10MB (byte[])
Kafka Broker:    13MB (JSON serialized)
Processing:      10MB (byte[])
────────────────────────────
Итого:           ~43MB памяти
```

### С S3/MinIO (10MB файл):
```
API Gateway:     ~1KB (URL string)
Request Service: ~1KB (URL string)
Kafka Broker:    ~200B (URL string)
Processing:     10MB (только во время обработки)
S3:             10MB (1 копия)
────────────────────────────
Итого:           ~10MB + небольшие строки
```

**Экономия памяти: ~75%**

## Временная диаграмма

### Текущий подход:
```
Клиент ──┐
         │
         ├─► API Gateway ──┐ (сериализация)
         │                 │
         │                 ├─► Request Service ──┐ (сериализация)
         │                 │                     │
         │                 │                     ├─► Kafka ──┐ (хранение)
         │                 │                     │           │
         │                 │                     │           ├─► Processing (десериализация)
         │                 │                     │           │
Время:   │                 │                     │           │
0ms ─────┴─────────────────┴─────────────────────┴───────────┴─► 100ms+
```

### С S3/MinIO:
```
Клиент ──┐
         │
         ├─► API Gateway ──┐ (загрузка в S3)
         │                 │
         │                 ├─► S3 ──┐
         │                 │        │
         │                 │        │
         │                 ├─► Request Service ──┐ (отправка URL)
         │                 │                     │
         │                 │                     ├─► Kafka ──┐ (маленькое сообщение)
         │                 │                     │           │
         │                 │                     │           ├─► Processing ──┐ (скачивание)
         │                 │                     │           │                │
         │                 │                     │           │                ├─► S3
Время:   │                 │                     │           │                │
0ms ─────┴─────────────────┴─────────────────────┴───────────┴────────────────┴─► 50ms+
```

**Улучшение производительности: ~50%**
